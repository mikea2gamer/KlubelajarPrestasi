# Klubelajar Prestasi — Android Studio

Aplikasi Android sederhana untuk bimbingan online Klubelajar Prestasi.

## Fitur
- Login Admin dan User.
- User: Jadwal, Pelajaran/Kursus, Nilai, Pesan Admin, Link Zoom, Profil.
- Admin langsung masuk ke Admin Dashboard.
- Admin dapat menambah/edit data siswa.
- Admin dapat menambah/menghapus/mengedit kursus siswa.
- Admin dapat memberikan nilai.
- Admin dapat mengirim pesan.
- Admin dapat mengirim link Zoom.
- Admin dapat menambah jadwal.
- Data demo disimpan menggunakan SQLite lokal.
- Warna utama: `#083074`.
- Logo Klubelajar dan gambar "Supported by 2026" sudah dimasukkan ke aplikasi.

## Akun demo
- Admin: `admin` / `admin123`
- User: `siswa` / `siswa123`

## Cara menjalankan
1. Extract ZIP.
2. Buka folder `KlubelajarPrestasi` di Android Studio.
3. Tunggu Gradle Sync selesai.
4. Jalankan pada emulator atau HP Android.
5. Untuk produksi, ganti password demo dan pindahkan database ke server/API.

Catatan: versi ini sengaja dibuat sederhana dan lokal agar mudah dipahami untuk tugas/proyek sekolah. Belum memakai Firebase/backend online.

## UI
Tampilan diperbarui dengan dashboard card, rounded buttons, hierarchy yang lebih jelas, dan branding Klubelajar yang tetap dominan. Fungsionalitas Java/SQLite tetap sama.
